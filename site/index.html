A container engine with no daemon

One static binary. It runs Docker and OCI images, and stores them file by file: a file that many images share is kept once.

Features

No daemonWhen no container runs, nothing runs.
One static binaryAbout 4 MB on Linux.
Files, not layersA file that many images share is stored once and cached once.
FastA container starts in about 4 ms on Linux.
Works with Docker toolsDocker and OCI images, the docker CLI, Compose and buildx.
With or without rootThe same program works both ways.
Linux, macOS, Windowsx86_64 and arm64. Windows support is experimental.

Layers and files

  • Layer stores (Docker, Podman, Kiri) keep each layer whole. When an image is built again, the same files go into a new layer, and are stored and cached again.
  • podbag keeps each file once. An image is a list of paths that point to the files.
  • For 8 Spring services in 2 releases: 902 MiB on disk against Docker's 2,970 MiB, and 324 MiB of page cache against 982 MiB.

Install

Install script (Linux and macOS)

curl -fsSL https://raw.githubusercontent.com/SteelCrab/podbag/main/install.sh | sh
  • Downloads the file for your system and checks its SHA-256 sum.
  • Installs it in /usr/local/bin, with sudo when needed.
  • On Ubuntu 24.04 and later, adds the AppArmor profile that rootless containers need.

Build from source

See docs/build.md for Linux, macOS and Windows.

Use

podbag run --rm alpine echo hello                 # pull the image if needed, run, remove
podbag run -d --name web -p 8080:80 nginx:alpine  # run in the background
podbag ps                                         # list containers
podbag logs -f web                                # follow the logs
podbag exec -it web sh                            # open a shell in the container
podbag stop web && podbag rm web                  # stop and remove

With the docker CLI, Compose and buildx

podbag system service &      # Linux (on macOS: podbag vm start)
export DOCKER_HOST=unix://$XDG_RUNTIME_DIR/podbag/docker.sock
docker compose up -d
